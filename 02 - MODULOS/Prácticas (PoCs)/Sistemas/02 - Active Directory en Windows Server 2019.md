# 🖥️ Active Directory en Windows Server 2019

## 📋 Laboratorio Integral de Administración de Dominios y Directivas de Seguridad

**Active Directory (AD DS)** es el servicio de directorio desarrollado por **Microsoft** fundamental para la gestión centralizada y estructurada de identidades, autenticación, recursos y directivas de seguridad corporativas en redes empresariales.

# Introducción a las DevTools de Firefox

Curso práctico dirigido a alumnos con conocimientos previos de HTML, CSS
      y JavaScript básico. Cada módulo es una página independiente que combina
      teoría y una zona de práctica real sobre la que trabajar directamente
      con las herramientas de desarrollador.
